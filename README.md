# 席替え（sekigae）

教室の席替えをブラウザだけで行うアプリです。データはブラウザの中と、自分で保存したファイルにだけ残り、サーバーには何も送りません。

公開先：https://sekigae.nanaryo.cc （Cloudflare Workers の静的アセットで配信）

## できること

- **席の数**：縦・横の席数を指定（各 1〜12 席）
- **使えない席**：席をクリック →「使えない席にする」
- **固定**：席をクリック →「番号を指定して固定」で、特定の出席番号の人をその席に固定
- **前回までの席と被らない席替え**：席替えの結果を「この席順を保存」で JSON ファイルに保存し、次回「前回までの席」に読み込む（最大 10 件・複数選択／ドラッグ＆ドロップ可）。チェックの入った履歴と同じ席には、固定した人を除いて**絶対に**座らせません。条件を満たす並びが存在しないときは、理由を表示して止まります
- **アニメーション**：カードが入れ替わりながら新しい席へ移動（ふつう／はやい／なし）
- そのほか：欠番、窓の位置、先生から見た向きへの反転、全画面表示、印刷

## 席替えのしくみ

1. 固定の人を先に置く
2. 残りの人と空いている席で「座ってよい組み合わせ」を作り、ランダム順の二部マッチングで条件を満たす並びを必ず 1 つ見つける（見つからなければ失敗を表示）
3. 条件を保ったまま入れ替えを大量に繰り返して混ぜ、偏りのない並びにする

乱数は `crypto.getRandomValues` を使っています。ロジックは `src/model.ts`、ファイル形式は `src/seatfile.ts` です。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # ロジックのテスト（vitest）
npm run typecheck
npm run deploy     # ビルドして Cloudflare にデプロイ（要 wrangler ログイン）
```
